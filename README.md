# Portfolio

My personal website: https://sudhanshu-pandey-18.github.io

A single page with my projects, experience, publication, skills and contact links. Built with plain HTML, CSS and JavaScript, no framework or build step, and hosted on GitHub Pages.

## Features

- Responsive layout with a collapsible menu on phones
- Light and dark theme based on the system setting
- Active section highlighted in the nav while scrolling
- Keyboard friendly (skip link, visible focus styles) and respects reduced-motion settings
- Compressed images, about 360 KB for the whole page

## Structure

```
index.html      page content
style.css       styles, including dark mode and breakpoints
script.js       mobile menu, active nav link, footer year
assets/         favicon and images
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.
